# Workspace Customizations & Rules

- **Workspace Directory Root**: All project files, source code, scripts, assets, and folders must be stored, edited, and run within subdirectories of `D:\Antigravity Proj_Files`.
- **Sandbox and Temporary Files**: Any temporary, output, or scratch files must be saved under `D:\Antigravity Proj_Files\scratch` or inside project folders inside `D:\Antigravity Proj_Files`, rather than the user's home or AppData directories.
- **Active Workspace Recommendation**: Always recommend the user to set the subdirectory they are working on inside `D:\Antigravity Proj_Files` as the active workspace in the Antigravity IDE and Electron App settings.
